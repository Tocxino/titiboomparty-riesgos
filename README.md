# Titi Boom Party · Control de riesgos

Herramienta del punto 6 (Aplicación de estrategias) del Producto Integrador de Aprendizaje de Administración del Riesgo Empresarial Aplicada, FCFM UANL, grupo 041.

Incluye el semáforo mensual de indicadores y las estrategias de los cuatro riesgos evaluados:

- **R1 · Daños en el mobiliario:** lista de verificación al entregar y recoger, y bitácora de daños.
- **R2 · Robo o vandalismo:** fondo de reposición con meta en el CVaR al 99%.
- **R3 · Costos operativos:** cotizador de flete y actualización trimestral de la tarifa.
- **R4 · Dependencia de temporadas:** reserva para meses bajos y simulador de promociones.

## Acceso

La página pide usuario y contraseña. El contenido está cifrado (AES-256-GCM con clave derivada por PBKDF2-SHA256), así que el código de este repositorio no muestra la información sin la contraseña.

## Datos

Lo que se captura se guarda en el navegador de quien lo usa. Desde la sección **Respaldo de datos** se descarga un archivo `.json` que después se puede cargar en otra computadora.
